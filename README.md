Visualización de una **nebulosa cósmica en 3D** creada con HTML, CSS y JavaScript.

## 🚀 Tecnologías

- HTML5
- CSS3
- JavaScript

## ✨ Características

- 🌌 Efecto galaxia / nebulosa cósmica
- ✨ Animaciones suaves tipo espacio profundo
- 🎨 Efectos visuales dinámicos
- ⚡ Optimizado para navegador
- 🧠 Estilo creativo y experimental

```
galaxia-3d-nebulosa-cosmica/
│
├── galaxia_3D.html

├── script.js
```

1. Descarga el proyecto
